明白，先看报错原文。
bash · stderr2.4s
$ tsc -b
../app/src/custom-elements.d.ts(1,1): error TS1128: Declaration or statement expected.
../app/src/custom-elements.d.ts(1,2): error TS1128: Declaration or statement expected.
packages/app/src/custom-elements.d.ts不是 TypeScript
../../ui/src/custom-elements.d.ts

文件内容只有一行路径，说明它是指向 ui 包的符号链接；Windows 检出时没有创建链接的权限，就落成了纯文本，TS 自然解析失败。

把仓库里 43 个符号链接实体化成真实文件即可，内容从目标文件复制。
