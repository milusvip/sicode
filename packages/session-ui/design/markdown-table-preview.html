落地要点
  • 滚动容器从 table 挪到外层 div：现在 table { display: block; overflow-x: auto } 会让表格脱离表格布局，列宽算不准，也没法做 sticky 表头。
  • 表头 sticky：th { position: sticky; top: 0 }，宽表横滑时列名一直可见。
  • 数字列右对齐：marked 会把 | ---: | 输出成 align="right"，但现有 CSS 用 text-align: start 把它覆盖了。应该让 [align="right"] 生效并加 tabular-nums。
  • 斑马纹：rgba(255,255,255,0.018)，深色下几乎看不见但能帮忙对行；浅色主题用 rgba(0,0,0,0.02)。
  • padding 12 → 8/12：手机上 12px 四周太占宽度，改成纵向 7–8px、横向 9–12px。
  • 边框：给整张表加 1px 外框 + 圆角 8px，比现在只有横线更像"一块内容"。
  • 右上角操作条：复制（TSV，可直接粘 Excel）/ 下载 CSV / 下载 PNG / 放大。桌面 hover 才出现，触屏常驻；opacity 淡入不占布局。
