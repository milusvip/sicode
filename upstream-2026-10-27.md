## 头条：GUI 插件化改名，这是战略分叉点

`dae4077a96 feat(plugin): add OpenCode Desktop GUI plugins (#55246)` — 1179 文件、+14712/−9095，其中 **928 个是 rename**。

它把全局的 `extension` 改叫 `plugin`：

- `packages/gui-extensions/` → `packages/gui-plugins/`（目录消失）
- `packages/app/src/runtime/extension/` → `packages/app/src/runtime/plugin/`
- 组件、测试、fixture 里的 `extension-host` → `plugin-host`，`mobile-extensions` → `mobile-plugins`

对我们的意义：二开代码里 `gui-extensions/src/debug/*` 我们加了约 335 行、`gui-extensions/src/browser/*` 也改过。这条一旦要跟，那些改动得整体搬到新路径，并且所有 `@opencode/gui-extensions` 的 import 全要改。

**这是「跟到底」或「永远不跟」的二选一**，跟 patchmark 那次同性质。不跟的代价是：以后所有 import `@opencode/gui-plugins` 的 app/desktop 提交都不能摘。
