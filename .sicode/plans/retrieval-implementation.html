④ 结构层直接立项：与验证并行，验证结果修正设计。
要解决的问题：模型用中文描述意图时，在英文代码库里靠猜关键词定位，慢会话 21 轮、88% 步数花在探索。
验收指标（贯穿所有阶段）： ① 探索调用数 / edit 数的比值（现在基线 33:4 ≈ 8:1，目标 < 4:1）· ② 首 5 轮内命中目标文件的比例 · ③ 同类任务的总轮数

第一手逆向校准（cursor逆向专区文档，2026-10-24 实测）

  • 来源：D:\软件丨工具\cursor逆向专区\文档\ —— Cursor-本地Trigram索引存储结构 / Cursor-本地检索与索引全链路（对真实仓库 + crepectl 实测，非博客二手信息）
  • 抄能力最小清单（逆向文档原文）：① commit 级文件倒排（可选，加速用）② 工具执行时 ripgrep 并搜 unsaved editors（必须，「刚写的就能搜到」）③ 返回 path+line+text（必须）④ 不要为 grep 实现 Merkle/向量合并（不要）
  • adoption 手法（Cursor 亲测）：Cursor 把语义与正则分成不同工具、不自动混排；我们无语义层，对应的做法是 grep/glob/read 三层工具分工明确、output_mode 默认 content 但用工具描述教模型自选——照此设计
  • 三条管道别揉一起（逆向图）：本地文本倒排（Crepe）/ Merkle 云端增量 / 语义向量检索是三条独立管道——我们只做前两类（trigram 倒排、repo map 调用边），语义向量检索明确不做，其余不合并

验证方法（每阶段同一把尺，v2 加强）

  • 黄金问题集：从真实会话收 20~30 条「中文意图定位」问题（设置页留白、token 字样、反代卡住…），每条人工标注目标文件:行号
  • 二值评分：前 5 轮是否命中目标文件（recall@5）；总轮数、工具调用数作辅助指标
  • 指标按任务类型分层（v2）：探索/edit 比在「提问型」和「改码型」任务上基线不同，混在一起比会失真——分两层各记各的
  • A/B 配对跑（v2）：开关切换新旧行为，同一问题新旧各跑、每条至少 3 次取多数（免费模型波动大，2 次会翻转）；报告区间而不是单点数
  • 指标进 notes.md 对应区域，按阶段更新

落地注意（v2 新增）

  • 增量策略统一（v6 明确）：不做后台 watcher 守护进程（CodeGraph 那种，资源代价不值）。1a 零索引；1b 无常驻索引（文件列表走 ripgrep、内容按需读）；3a 沿用 repo map 现有 mtime+size 懒失效（冷启 5.8s/热 0.39s，已验证）；trigram 用 commit 锚定式——索引锚 git commit、未提交改动叠加其上、仅大漂移时重建（Cursor 官方机制），非 git 仓库查询时按 mtime 懒检查。本仓全量重建也才 ~7s（逆向实测同量级），增量压力天然小
  • 与现有 hint 机制的关系：查询扩展指引走 system.txt 静态区 + 工具描述，不新增 hint 注入点——context.ts 已有 context-hints/clarify-hint/design-hint 三个，不再挤
  • 并行会话冲突：prompt 文件正被其他会话改，落地前先 git status 确认，改完立即提交不留在工作区
  • 回滚开关：1a 用 OPENCODE_QEXPAND=0，1b 用 OPENCODE_RANKED=0；阶段二子代理用 agent 配置开关；每个能力独立可关

兼容性：开箱即用与全模型适配（硬约束）

  • 开箱即用：全部动作（指引/加权/结构/子代理）100% 开箱，零下载、零用户动作、零模型——纯词法 + 结构 + 隔离搜索，全程免费本地。
  • 与对话模型解耦：没有任何本地模型，检索不碰 embedding，与用户用什么对话模型（DeepSeek 免费档/Kimi/任何）完全无关。
  • 不依赖模型自觉的两条保险：BM25F 建议由代码逻辑触发（grep 空结果 → 自动注入），结构建议同理——弱模型不照做指引也躲不过；强模型额外受益于提示词指引
  • 工具协议零特殊处理：新工具走 opencode 现有 OpenAI-compatible tool calling 通道，DeepSeek function calling 标准支持
  • 预期差如实登记：同一指引强模型照做度高、免费档低——A/B 按模型分档测，「自动注入」比「提示词恳求」重要
一句话方案：三层原生全做——词法（查询扩展 + BM25F）、结构（调用边/impact，CodeGraph 只当内部参考）、隔离搜索子代理；每层独立可验收、独立可回滚，零模型、零下载、开箱即用。
