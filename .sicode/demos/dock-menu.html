逐条对照

现状提案依据
1 身份区两行：28px 头像 + 名称 + 「数据只保存在这台电脑」 一行 26px 头像 + 名称，隐私说明降为 pill 上的锁形提示 这句是给一次性的信任背书，不需要在每次开菜单时重复占 16px 高度
2 版本号独占一行「版本 … · 桌面版」，11px 灰色散文 版本下沉为身份副行，--v2-font-family-code 11px；「桌面版」右对齐为同位语 DESIGN.md：数字列用 mono；副行与标题的间距（3px）小于组间距，天然成组
3 版本号第二次出现在「关于」行 → 标签被 truncate 成「关…」 「关于」行不带 hint，标签完整；版本只在上面出现一次 这是实机截图里的真实缺陷：row 内 lb 是 flex-1 truncate、hint 是 shrink-0，hint 越长标签越短
4 — 悬停身份区出现复制按钮，点击变绿勾 版本号真正的用途是报 bug 时贴给开发者；省掉手工选中 25 个字符
5 两条分隔线把菜单切成三段 只保留身份区下方一条；次菜单用 6px 距离分组 DESIGN.md：「Separate groups with distance, not with an extra border, divider」
6 固定 w-[248px]，短菜单也这么宽 236px 起，长标签可把卡片撑到 288px 对齐 context-menu.css 的 max-content / min-width / max-width 三分支
7 行高 30px，hover 底色，无键盘焦点样式 同步 30px / hover；增加 :focus-visible 内描边与 chevron 开合旋转、指向触发件的箭头 卡片是 Kobalte Popover，Tab 进入时必须有可见落点；箭头把浮层和触发件连成一条视线

范围说明：此页只提出视觉与信息层级变更，不改菜单项、不改跳转目标。
落点：packages/app/src/shell/dock-toolbar.tsx（结构 + class）；若箭头/焦点态需要复用，Popover.Arrow 与 focus-visible 描边属 Kobalte 原生能力，无需新增 token。
